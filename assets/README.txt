fonts and images go here.

you are welcome to use any of the assets listed here already, as they're free to use (if you're doing a mod you should make your own logo though. i recommend using a program like GIMP (which is free) or photoshop to create it.) the .xcf files provided are GIMP project files that you can use to edit some of these icons.

the SVG icons came from tabler.io.

to round icon borders, i recommend using pinetools.com/round-corners-image.

some images may simply be too large and need to be smaller in order for the pages to load quickly, and for that i recommend the program Caesium Image Compressor, or the website tinypng.com (both are free).
